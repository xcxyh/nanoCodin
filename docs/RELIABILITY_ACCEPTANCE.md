# 可靠性修复实施与验收记录

## 代码与本地证据

- 模型总预算、无数据预算及有限重试；SDK 隐式重试关闭。取消、认证、额度、限流、网络及协议错误分别报告，支持追踪 attempts/duration/HTTP/response bytes。
- final schema 统一；内容过滤不能假成功；完成 hook 返回后检查取消；未知审批值不执行。
- 默认工具仍为八项。create 不覆盖；str_replace 增加 expectedHash 保护的显式 rewrite。读取有类型/字节/遍历限制，续读行列准确；已知前置失败与不确定副作用分开。
- 历史字段先限额，未解决错误、最近成功写入及有效检查优先保留；原生调用结果成组配对。
- DeepSeek 所需 reasoning_content 作为私有协议续接数据保留，不在 UI 或普通文本历史展示；缺失/超限时提供历史事实，不重放工具。兼容代理仅在明确协议要求时启用。
- provider 默认值隔离、中文/命名空间 skill、规范工作区路径、损坏会话诊断、工具字典特殊名称修复。
- 覆盖率统计扩大到全部 src。CI 增加 Linux/macOS 和最低运行版本打包消费者；发布流程增加完整回归、覆盖率和打包检查。最低运行版本声明改为 Node 20.5。

回归包含：fake clock 慢响应/保活/超时、Retry-After/认证/取消、实际 SDK 原生消息及续接、HTTP 整文件改写与构建、超时落盘和恢复不重放、文件限额与版本冲突、已知错误与小历史预算、Unicode skill 和符号链接会话身份。

不将测试数量或全模块覆盖率当作业务完成证明。最终数字和远端 CI 以交付时对应提交的报告为准。

本地最终复核：`typecheck`、191 项测试、全模块覆盖率（行覆盖率 91.75%）、构建、打包消费者检查和 `git diff --check` 均通过。打包检查包含声明文件、公开入口、核心依赖隔离及模拟 HTTP 下的原生 SDK 传输；不发送真实模型请求。
